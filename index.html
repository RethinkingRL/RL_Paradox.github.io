Abstract

This page repackages the ACL LuaLaTeX and XeLaTeX template PDF into a more polished academic web presentation. The overall structure intentionally mirrors the ORACLE-GAP site, but the content flow has been adapted for a single document rather than a full research project with multiple figures, datasets, and experiments.

The result is a cleaner publication experience: clear title and action buttons at the top, a compact overview section for quick scanning, a highlights area that explains what the page offers, and a large embedded reader so the PDF remains the main focus throughout the visit.

Why This Layout

The PDF is now integrated into the page instead of attached to it

In the reference ORACLE-GAP site, each section builds toward the main research story. Here, the same approach is used to build toward the document itself. The title block sets context, the overview block explains purpose, and the reader section becomes the natural destination.

That makes the page easier to present publicly, easier to scan for first-time visitors, and more suitable for GitHub Pages deployment than a plain PDF link on its own.
